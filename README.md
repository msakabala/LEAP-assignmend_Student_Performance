# Student Performance — Final Project Portfolio

**Scenario 2: Understanding Student Performance**

This portfolio investigates final Mathematics grades and pass/fail outcomes among 395 students in the UCI Student Performance Mathematics dataset.

## Contents
- `Student_Performance_Analysis.R` — reproducible R analysis based on the course starter.
- `Student_Performance_Analytical_Report.pdf` — six-question analytical report.
- `Student_Performance_Decision_Maker_Presentation.pptx` — five-slide presentation for school decision-makers.
- `student-mat.csv` — input data.
- PNG figures — selected figures used in the report and presentation.

## Run the analysis
1. Open RStudio and set the working directory to this folder.
2. Open `Student_Performance_Analysis.R` and run from top to bottom.
3. The script installs missing ggplot2, dplyr and broom packages if needed.

Main models deliberately exclude earlier grades G1 and G2. Findings are associations, not evidence of causation.

**Source:** Cortez, P. (2008), UCI Student Performance Dataset, https://doi.org/10.24432/C5TG7T.
